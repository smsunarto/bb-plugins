## Thread title (GTD Sidebar)

When the user clearly moves this thread to different work that its title no longer describes, rename the thread with one command:

`bb gtd-sidebar rename --title "<new title>"`

- Rename only for a clear change of direction, such as a new, unrelated task. Follow-ups, fixes, tests, reviews, commits, and shipping for the same task are the same work.
- Decide from the conversation alone. The rules below are complete, so run no command to read the current title or the naming rules first.
- Rename once per change of direction. Leave the title alone to polish wording or to report progress.
- The command prints the old and new titles. If it rejects the title, it says why; fix the title and run it once more.
