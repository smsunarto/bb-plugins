### Core behavior

This phase is the credential boundary, so review fail-closed behavior before workflow call sites. Follow each secret into an exact repository URL rewrite, then into the temporary Git configuration shared with GameCI. The invariant is that both private repositories remain fetchable without ever writing credentials into tracked package files or granting a token broader repository reach than necessary.

#### Configure two repository-scoped credentials without rewriting package files

The composite action replaces fallback token selection and manifest mutation with two required, fine-grained read-only credentials. Bash and PowerShell implementations both fail closed when either repository token is absent, create a temporary global Git config, and add exact `insteadOf` rewrites for only the monorepo and backend URLs.

Keeping credentials out of `Packages/manifest.json` preserves a deterministic tracked dependency graph and prevents token-bearing file changes from leaking into caches or artifacts. Exporting the temporary config path and entries through `GITHUB_ENV` is also intentional: Unity/GameCI resolves packages in a container that would not otherwise inherit the runner's global Git configuration.

### Tests and verification

The EditMode job provides executable evidence but also handles high-value secrets and a serialized Unity license. Review the trust condition first, then test execution, unconditional license return, and artifact upload. Passing tests are insufficient if forked code can access secrets or a failing run can strand the license and discard diagnostics.

#### Run EditMode evidence only inside the trusted secret boundary

The new EditMode job restores LFS assets, configures private package access, caches Unity's Library, runs the focused tests, returns the license, and uploads results. Its condition admits non-PR trusted events and same-repository PRs authored by owners, members, or collaborators; fork and untrusted-author PRs cannot receive the package or Unity secrets.

Serial concurrency prevents simultaneous jobs from contending for the same Unity license. Cleanup and artifact upload use `always()`, preserving both license hygiene and test evidence when the runner fails partway through execution. Qodana receives the same trust condition because it also restores the private Unity dependency graph.
