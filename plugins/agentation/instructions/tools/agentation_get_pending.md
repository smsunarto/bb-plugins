Read open feedback for one page: returns its pending and acknowledged annotations with the bb route, owning plugin, SDK UI registration, and DOM selector. Pass a `sessionId` from `agentation_list_sessions` or an annotation batch.

Use `agentation_get_all_pending` for open feedback across pages, or `agentation_get_session` for this page's complete history. Acknowledge an annotation with `agentation_acknowledge` when you pick it up.
