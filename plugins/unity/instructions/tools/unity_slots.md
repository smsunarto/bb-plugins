Manage persistent Rampage client checkout slots. Register an existing independent clone with its BB project and host, acquire a lease from a thread in that checkout, then claim its exact Unity Editor with unity_manage. Slots retain their Library cache and GitButler state across tasks. List exposes lease IDs only to their owning caller. Release requires all Editor claims released, the main Editor and MPPM clients closed, and other agents stopped. Failed or interrupted verification quarantines the slot. Recovery requires explicit completion evidence and confirmation; another thread may recover only an archived or deleted owner's slot. Retirement unregisters an available slot and preserves every checkout file. No automatic expiry, takeover, branch switching, stashing, cleanup or deletion.
