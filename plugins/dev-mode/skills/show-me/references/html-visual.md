# HTML visual

For a visual UI, layout, state comparison, or concept too dense for Mermaid, write one focused visual: a diagram, an infographic, or a short slide deck, whichever fits the point.

- For product-specific visuals, match the product's colors, type, spacing, and components.
- Use real labels and data when available. Label illustrative values or proposed states.
- Fit the intended viewing size. Add responsive behavior when the visual will be used at different sizes.
- Use an available Canvas tool when it fits the requested output. For a standalone HTML artifact, write `show-me-<description>.html` and present it.
