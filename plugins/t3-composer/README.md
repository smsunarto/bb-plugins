# T3 Composer

A fork of BB’s composer styled after the ChatGPT macOS app, with BB’s 12px corner radius: a rounded surface, a 14px/20px editor (16px on touch screens), 28px controls, a `+` menu, the model pill and the permission mode on the left, and a round send button. As in ChatGPT, the project, machine and branch row sits in a full-width tray attached above the surface, and attachments show as tiles above the text, with annotations and comments counted in chips instead of inline pills. BB renders that row and its menus, so the plugin moves and restyles them with CSS keyed to BB’s `data-follow-up-composer-footer` and `data-new-thread-footer` attributes and the Project and Environment menu labels; the menu styling applies wherever BB shows those menus. Colors and the selected font follow the active BB theme. Save draft is a direct icon action beside the attachment and microphone buttons, including in collapsed composers. BB retains its explicit compact/expanded layout selection so model and plugin controls remain available; the renderer does not automatically collapse one-line drafts like ChatGPT.

Install this directory with `bb plugin install .`, then choose **T3 Composer** under **Settings → Appearance → Composer** if Automatic has not selected it. Requires BB 0.47.1 and SDK 0.6.79. To switch back, choose the built-in **Composer** there.

Drafts, uploads, voice input, history, model selection, and sending use BB’s public composer API. Save draft holds the message in BB’s queue until you send it manually. This plugin replaces their presentation in thread, new-thread, queued-message, and sent-message composers. It retains BB’s prompt-action menu and shows other plugins’ composer actions, including BB’s overflow menu, after the permission mode; compact composers omit them as BB’s composer does. Alternate send actions remain available with a hardware keyboard. The removed send-options menu and long-press sheet are not available on touch-only devices. Save draft follows the built-in Drafts plugin’s scope and availability, so Drafts must be enabled. BB excludes queued-message and sent-message editors.
