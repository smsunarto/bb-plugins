# Lens: Brief

Check the change against its brief, item by item.

- For each done-means item, find the code, test or run that meets it. Mark it met, partly met, or not met, with the evidence.
- List every change outside the brief's scope: files, behavior or repos the brief put out of scope.
- Flag a done-means item that is met only by a test that asserts the implementation rather than the behavior.
- Report each gap as a finding with the item's number, the file and line, and what is missing.
