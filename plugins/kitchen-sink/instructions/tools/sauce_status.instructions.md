For Sauce Labs real-device work (Sauce Live, mobile device checks, mobile bug hunts), use the `sauce_*` tools, starting with `sauce_status`, and read the `sauce-live` skill before `sauce_start`. They are the Sauce Live web UI route: they drive the signed-in Chrome on the bb server machine. A task that asks you to check Sauce in a local browser, sign in with Google, or test by hand in the Sauce web UI is done through these tools, and `sauce_status` returning `ready` means that check passed. Do not launch another browser or use computer use for Sauce; it cannot share the sign-in or the one device. They replace the old `Logs/sauce-tune` scripts.
