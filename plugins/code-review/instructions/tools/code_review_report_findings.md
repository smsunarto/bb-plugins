Report the findings of a Code Review pull request review to the Code Review panel, where the reviewer reads them beside the diff and turns the ones they agree with into draft comments. Call it exactly once, after the whole review, with every finding; call it with an empty `findings` list when there are none. A later call replaces the earlier report.

Each finding names the file `path` at the pull request's head commit and the `line` its comment sits on, numbered on `side` `RIGHT` (the head version) unless the issue is about deleted code (`LEFT`, base version numbering). Give `startLine` for a multi-line range. `priority` is 0 to 3 (P0 release blocker, P1 urgent, P2 ordinary defect, P3 low impact). `title` is an imperative sentence without the priority tag, and `body` is one short paragraph explaining the affected scenario and why the behavior is wrong.
