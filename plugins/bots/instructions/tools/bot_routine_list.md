List this bot's routines: scheduled instructions that run in subthreads of the bot's main chat. Returns each routine's id, name, instruction, cron, timezone, projectId, execution (its harness, or null for the bot's default), threadMode, and threadId (its latest run's conversation, null until the first run), plus automation state (enabled, nextRunAt, lastRunAt, lastRunStatus, lastError), lastRun, and the projects a routine may run in.

Call it before bot_routine_update to get a routineId, when the user asks what routines exist, when one runs next, or how its last run went, and before creating a routine to avoid a duplicate. Dr. Bot can pass bot (another bot's ID or name) to list that bot's routines.

RETURNS
lastRunStatus succeeded means Automations delivered the instruction, not that the work finished. lastRun reads the run's conversation: `{ threadId, status, updatedAt, reply }`, where status is the thread's state (idle, active, error, archived, ..., or reassigned when the conversation now belongs to another bot) and reply is the start of its latest answer, null while it is still working. Use lastRun to report whether a run finished, was blocked, or failed; read the full conversation with `bb thread log <threadId>` only when reply is not enough. An automationError means the schedule could not be read; report it instead of guessing the state.
