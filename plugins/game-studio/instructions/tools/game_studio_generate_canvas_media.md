Generate from a saved image, video, or 3D canvas node and its saved references, using the exact board revision returned by game_studio_canvas_context. For Tripo P2 the node's Front input is the approved image; pass its path as approvedImagePath to confirm it. Connected Left, Back and Right inputs are sent as further views. Video uses the Start and End inputs as its frames. Returns a persisted asynchronous job; collect with game_studio_generation. Outputs attach only while the saved source brief is unchanged. Unsaved UI drafts are never submitted.

Tripo model-3d recipes use the model port: tripo-smart-uv generates one UV candidate; inspect its GLB in the model viewer's UV mode, choose its take, then run a connected tripo-apply-uv node. Only the applied output can feed tripo-texture or tripo-pbr. Source task and candidate operator identities come from saved jobs. Locally changed GLB bytes are snapshotted and imported as a new Tripo model; modified candidates must be regenerated before application.
