Generate images from a creative brief and optional project-relative reference images. Default Google Nano Banana 2.1 produces one image; Midjourney produces four candidates. Returns a persisted asynchronous job. Requires user-authorized generation scope. Use a stable requestId for retries, then game_studio_generation to collect and catalog outputs. Credentials are server-managed; no CLI commands or keys are needed. A paid generation (Google, Midjourney, Fal, or Tripo) that an agent starts waits for the person's approval first: the tool answers with a waiting notice, and its result arrives later as a message, either the started job or {declined:true,reason,detail}, where reason is "declined", "timeout" (nobody answered within ten minutes), or why the form closed; none of these means the person saw and refused it except "declined". Approval covers the run's batch and the retries its node's review may add; a game the person approved in advance, or an earlier approval of the same request id that still has budget, skips the form. BB-model runs never ask.
