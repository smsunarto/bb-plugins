Generate images from a creative brief and optional project-relative reference images. Default Google Nano Banana 2.1 produces one image; Midjourney produces four candidates. Returns a persisted asynchronous job. Requires user-authorized generation scope. Use a stable requestId for retries, then game_studio_generation to collect and catalog outputs. Credentials are server-managed; no CLI commands or keys are needed. A paid generation (Google, Midjourney, Fal, or Tripo) that an agent starts waits for the person's approval first: the tool answers with a waiting notice, and its result arrives later as a message, either the started job or {declined:true}. Approval covers the run's batch and the retries its review may add; a game the person approved in advance skips the form. BB-model runs never ask.
