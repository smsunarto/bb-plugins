For Game Studio design and canvas work, read game_studio_canvas_context first. Generate image, video, and 3D assets through Game Studio tools; provider CLIs and credentials are implementation details. Preserve requestId across retries. Poll game_studio_generation until terminal and inspect candidates before approving import.
