Read a Game Studio workflow in bounded pages. With gameId alone, returns board summaries and exact revisions, main document path, counts, and generation providers. Add boardId to read semantic nodes; nodeIds selects up to 20. section selects nodes (default), edges, assets, or documents. Follow nextOffset using offset; limit is 1–50. Layout and bulky histories are omitted, with omittedDataKeys naming excluded node fields. Read any full node data field in chunks with boardId and field:{nodeId,key,offset,limit}; encoding identifies text or JSON. This also reads long prompts and take/review histories without overflowing context. Returns mediaDir, the host folder holding canvas/staging and canvas/inputs files as staging/ and inputs/. Read before work and after changes; generation and edits use the returned board.revision exactly. Requires a thread in the game's project and checkout, but reading does not need its slot lease. CLI equivalent: bb game-studio rpc canvasContext '{"gameId":"...","boardId":"..."}'.
