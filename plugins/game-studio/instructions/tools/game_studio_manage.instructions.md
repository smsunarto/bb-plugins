Target the claim's exact instance.projectPath and verify the selected Editor's PID matches instance.pid before a series of calls; stop and reclaim if its identity changes. Runtime claims authorize read-only calls. Shared Assets/Packages writes and scenario lifecycle require the main Editor's authoring claim; call status and write only when background.quiet is true. Track each detached Unity CLI job ID and wait for completion before release; this tool does not track new CLI jobs. Coordinate capture, focus and simulated input with every other claim owner on the host. Make no Unity CLI calls under a startup claim. Do not bypass another thread's claim through CLI, UI or agent-game. Direct calls cannot be intercepted. Preserve dirty scenes and finish native work before release.
