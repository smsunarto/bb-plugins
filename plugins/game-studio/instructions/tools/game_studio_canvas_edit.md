Edit an existing saved Game Studio workflow atomically using its exact board revision. operations (1–100): add_node with node:{id,type,title?,description?,data}; update_node with id and patch:{title?,description?,data?}; move_node with id and position:{x,y}; remove_node with id; connect with id,source,target,port?; disconnect with edge id; connect_asset with target,assetId,port? for a catalog image; remove_input with id and input:{key:"images"|"references",index} or input:{key:"promptSource"}. Add nodes before connecting them in the same batch. Uses the canvas UI's node defaults. Updates merge data keys and preserve outputs, histories, and untouched layout; generation history keys cannot be overwritten. Configure review:{enabled:true,retries:0,criteria:"..."} and judge:{enabled:true,criteria:"..."} in data. Connect writes both the visible wire and the model input and validates port type/capacity. Video ports: start/end; Tripo P2: front/left/back/right. Tripo processing recipes use model. For Smart UV use type:model-3d with data.recipe:tripo-smart-uv, then tripo-apply-uv; connect the chosen candidate to Apply UV before texture/PBR. An uploaded model can be selected with assetId on a model-3d node. Use connect/disconnect for node wires and connect_asset/remove_input for library or wireless inputs. remove_input indexes address the exact saved arrays, and remove any wire once its last corresponding input is removed. Library images/references may also be supplied on add_node; only existing image assets are accepted. Removing a node cleans incident wires and references, including promptSource. dryRun:true validates against the supplied revision without writing. Add run:{nodeId,requestId} to run a node of the edited board as soon as the edit is saved, its inputs without an output first (as game_studio_generate_canvas_media with upstream:true); the result then carries run:{jobs,waiting,gate?}, and a dry run carries run:{planned} instead. A paid run asks the person before anything is saved: the tool answers with a waiting notice, and the result arrives later as a message, either the saved edit with its run or {declined:true,saved:false} with the board unchanged. A saved edit returns editId; the studio shows the person what each edit changed and can put it back while it is still the board's latest content, so prefer one coherent batch per change over many small ones. A stale revision is rejected: reread the affected nodes, merge, then retry. Adds use estimated placement; move_node sets explicit positions until the next canvas open, which automatically arranges measured cards. Use the canvas UI's Arrange button for layout based on measured cards. Without run, it does not run generation or spend credits. Requires the game's thread checkout and owned Rampage slot when registered.
