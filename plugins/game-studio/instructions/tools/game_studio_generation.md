Read, resume, or stop waiting for a generation job. Status catalogs successful outputs in canvas/assets.json and adds image and video outputs to the source node as takes without replacing its chosen output. Resume only polls/downloads the existing provider task; it never submits a replacement. Cancel stops local waiting and does not cancel a paid provider task. An uncertain job without a taskId needs provider-side reconciliation before any new request.
Finish status collection before releasing a registered Rampage checkout. An unresolved dispatch holds the checkout until its saved job is accounted for.
A jobId that names a run the server still holds for its inputs answers {job:null,status:"waiting",run:{boardId,nodeId,requestedAt,error?}}; its job is created when the inputs land. Cancel drops the waiting run; resume has nothing to resume yet.
If a failed dispatch has no host job, status safely retires that request ID and returns job:null with status:not-submitted, releasing its checkout reservation. Use a new request ID only after that confirmation.
