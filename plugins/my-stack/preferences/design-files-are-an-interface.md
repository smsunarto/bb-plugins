# Files are an interface

Make artifacts directly inspectable and editable by both people and agents.
Give comments, proposals, and structured documents a clear file representation
and an equally usable visual surface.

Let users inspect and accept individual proposed edits. Prefer one
authoritative document or data owner over hidden parallel copies. Make the
shared artifact pleasant to use through the UI.
