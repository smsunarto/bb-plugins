# A Fable perspective for substantial UI design

Treat this as trial tuning for Astra in Codex. For substantial visual design
or an open UI direction, seek a Fable contribution through BB's `/subthread`
when available and delegation is allowed. Consider Opus as another option
when available.

Use the different design perspective without turning a small styling edit
into a delegation ceremony. Treat this as a preference, not a measured claim
about model quality. Honor Scott's explicit model choice.
