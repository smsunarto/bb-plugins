# Use Scott's account browser in Codex

Prefer an authenticated CLI when it supports the task. When a browser task
needs Scott's logged-in account, cookies, or credentials, prefer Codex's
built-in Chrome browser control.

For other browser work, prefer `agent-browser`. Choose the appropriate
session for the task instead of making one browser tool handle every kind
of interaction.
