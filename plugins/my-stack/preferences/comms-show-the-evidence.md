# Put evidence beside the claim

Ground explanations in the actual source or observed behavior. Put the
relevant file, diff, or small visual beside the claim. Prefer an annotated
flow when it explains the point more clearly than prose. In agent diagrams,
show explicit inputs, outputs, and who owns each part.

Distinguish source inspection, local tests, and observed production behavior.
Say which supports the conclusion. When asked for only a flowchart, let the
flowchart carry the explanation.
