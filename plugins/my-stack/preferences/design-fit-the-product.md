# Fit the product

Prefer familiar controls, clear hierarchy, and careful interaction details.
Start with existing product components and design tokens. In BB, default to
the SDK's UI surfaces, shadcn components, and the Monokai palette.

Use motion to explain a change or make an interaction feel responsive. Make
repeated actions feel immediate. Include implementation details in the
interface only when they help the user make a decision.
