## The fix

The teardown handler registers after `bootstrap`, so a throw inside `bootstrap`
leaks the claim. The call site is linked below.

<FileLink path="scripts/bb-dev-cli" line={87} label="scripts/bb-dev-cli:87" />

<DiffView path="scripts/bb-dev-cli">
```diff
@@ -84,7 +84,9 @@
   const port = await claimPort();
-  await bootstrap(port);
+  try {
+    await bootstrap(port);
+  } finally {
+    release(port);
+  }
```
