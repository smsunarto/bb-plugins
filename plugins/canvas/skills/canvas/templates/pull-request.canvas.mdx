## Summary

A canvas can now declare how it should look. Frontmatter at the top of the file names a style, and the parser records it on the document. Two styles ship: `default` keeps the current look, and `github` renders the body the way GitHub renders a markdown file, so a pull request or issue preview reads like the real page.

The parser accepts `style` as the only frontmatter key. An unknown style, an unknown key, or a malformed line becomes a positioned diagnostic, and the canvas falls back to `default`, so a typo never blanks the render. `bb canvas check` prints the resolved style in its success line.

The app side lands in a follow-up. This pull request covers the parser and the shared style module. Start the review at `shared/styles.ts`.
