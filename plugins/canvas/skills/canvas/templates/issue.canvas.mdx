## Summary

The frontmatter style lookup is case sensitive. A canvas that declares `style: GitHub` gets an `unknown-style` diagnostic and renders with the default style. The message suggests `github`, so the parser already knows what the author meant. An editor that capitalizes the first word of a value triggers this on every save.

## Steps to reproduce

1. Write a canvas whose first three lines are `---`, `style: GitHub`, and `---`.
2. Run `bb canvas check` on the file.
3. Open the file beside the chat.

## Expected

`bb canvas check` prints a success line that names `style github`, and the canvas renders with the GitHub look. Case should not matter for a value drawn from a fixed list of two names.

## Actual

`bb canvas check` prints `unknown style GitHub; did you mean github?` and exits 1. The canvas opens with the default style and a problem card at line 1.
