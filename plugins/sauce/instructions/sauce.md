For Sauce Labs real-device work (Sauce Live, mobile device checks, mobile bug hunts), use the `bb sauce` command from your shell, starting with `bb sauce status`, and read the `sauce-live` skill before `bb sauce start`. It is the Sauce Live web UI route: it drives the signed-in Chrome on the bb server machine. A task that asks you to check Sauce in a local browser, sign in with Google, or test by hand in the Sauce web UI is done through `bb sauce`, and `bb sauce status` returning `ready` means that check passed. Do not launch another browser or use computer use for Sauce; it cannot share the sign-in or the one device. `bb sauce` replaces the `sauce_*` tools and the old `Logs/sauce-tune` scripts.
